Reshme-Namma Pride - Project 52
Android App Development using GenAI - Agriculture / Sericulture

WHAT IS INCLUDED
1. Batch Tracker
   - Add silkworm batch name, breed, start date, and instar stage.

2. Climate Entry
   - Enter temperature and humidity.
   - Temperature is restricted to 10°C to 45°C.
   - Humidity is restricted to 20% to 100%.

3. Smart Advice Engine
   - Advice changes based on the current silkworm instar stage.
   - Status colors:
     SAFE = Green
     CAUTION = Orange
     DANGER = Red

4. Cocoon Harvest Timer
   - Shows approximate days left for cocoon / spinning tray transfer.

5. Room Database
   - Stores batch data.
   - Stores climate log history.

6. Share Summary
   - Shares a clean text report using Android share intent.

HOW TO OPEN
1. Extract the ZIP file.
2. Open Android Studio.
3. Click File > Open.
4. Select the ReshmeNammaPride folder.
5. Wait for Gradle Sync to complete.
6. Click Run.

PACKAGE NAME
com.example.reshmenammapride

IMPORTANT
This project uses Gradle plugin 8.7.3, Kotlin 2.0.21, Jetpack Compose, Material3, and Room Database.
If Android Studio asks to update Gradle/plugin versions, click Accept or Sync.
