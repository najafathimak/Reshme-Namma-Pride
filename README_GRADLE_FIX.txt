I changed the project to more stable Android Studio versions:
- Android Gradle Plugin: 8.5.2
- Kotlin: 2.0.0
- KSP: 2.0.0-1.0.24
- compileSdk/targetSdk: 34

HOW TO OPEN
1. Extract this ZIP.
2. Open Android Studio.
3. Click File > Open.
4. Select the folder named ReshmeNammaPride.
5. Wait for Gradle Sync.
6. If Android Studio asks to download Gradle/SDK, click Download/Install.
7. Run the app.

IMPORTANT
Open the ReshmeNammaPride folder only. Do not open the app folder directly.
